# Статистический план v1

План сохранён до расчёта статистических тестов. Он не является внешней предварительной регистрацией или независимым подтверждением. Известны формат и объём корпуса, присутствие вступительных басмал. Проверки относятся к перестановочным моделям данного файла; причинные, религиозные и межкорпусные выводы не следуют.

1. **Соседство длин**: среднее абсолютное различие числа токенов соседних аятов одной суры. Направление — меньше контроля. Две модели: перестановка аятов внутри каждой суры; перестановка последовательных блоков по 5 аятов внутри каждой суры (последний блок может быть короче). Вторая сохраняет больше локальной зависимости.
2. **Длина и положение**: модуль среднего произведения центрированных относительных позиций и центрированных длин, делённый на общий корень сумм квадратов (корреляция с удалённым средним каждой суры). Контроли те же. Число токенов, состав и границы сур сохраняются; меняется порядок аятов. Это описывает структуру порядка, не хронологию ниспослания.
3. **Письменные окончания**: доля соседних аятов с одинаковыми последними 2 либо 3 базовыми буквами последнего токена. Из исходника извлекаются Unicode-буквы без татвиля; фонетического утверждения о рифме нет. Те же перестановки аятов и блоков. Ограничения грамматики контролируются лишь частично.
4. **Лексика внутри аята**: для top-60 форм с частотой не ниже 100 сравнить начало/середину/конец. Позиция (i−0.5)/n; интервалы [0,1/3),[1/3,2/3),[2/3,1]. Ожидаемые значения вычисляются из количества каждой формы в каждом аяте и доступных мест каждого типа. Статистика — максимум Pearson-подобного отклонения по всем выбранным формам. В каждой симуляции повторяется весь выбор максимума; top-60 инвариантен к перестановке. Контроли: случайная перестановка токенов внутри аята; случайный циклический сдвиг внутри аята. Сдвиг сохраняет циклические последовательности, но вводит искусственную связь конца с началом. Ни одна модель не является генератором естественного арабского.

Первые три семейства: основной и альтернативный учёт басмалы. Последнее дополнительно сравнивает NFC и plain. Все строки первичного семейства (ожидается 24) входят в единую Holm-поправку FWER при α=0.05; допустима зависимость тестов. Отбор красивых строк после тестирования не сужает семейство. Число B=999 зафиксировано; p=(b+1)/(B+1), минимальный p=0.001. Сохраняются все симуляции, эффект относительно среднего контроля, его 2.5–97.5 процентили (интервал контрольной модели, не доверительный интервал точной частоты), seed и фактическая вариативность статистики. Константный контроль помечается непригодным.

Список включённых форм, соответствующие исходные token_id и адреса для проверки содержатся в таблицах и SQLite. Исключаются только явно отмеченные вступительные басмалы при scope=numbered. В профиль nfc включается огласованная форма; plain исключает ровно оговорённые знаки. Поправка охватывает предусмотренные альтернативы, но не устраняет неопределённость постановки человеком вопросов. Дополнительные гипотезы после просмотра будут записаны отдельно как exploratory.

Расчётная стоимость: около 24 тысяч оценок, 8 тысяч перестановок токенов (~0.6 млрд операций над индексами); память линейна по корпусу и числу форм, таблицы максимумов малы. Квадратичные пары токенов не материализуются.
