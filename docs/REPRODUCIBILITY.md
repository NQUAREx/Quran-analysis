# Пересчёт, происхождение и ограничения среды

Исследуется исключительно `Quran_text.txt` из `NQUAREx/Quran-analysis`. Репозиторий клонирован из доступного пользователю GitHub; ссылка на исходный commit и состояние рабочей копии находятся в `run_manifest.json`. Исходный файл в корне не редактируется; копия `data/raw/Quran_text.txt` и SHA-256 фиксируют точный объект анализа.

Python выбран для Unicode, таблиц и воспроизводимых статистических алгоритмов; SQLite — для полных индексов без отдельного сервера. NumPy/SciPy выполняют перестановочные проверки, Matplotlib — статические графики, openpyxl — XLSX. Главный HTML содержит данные и код интерфейса, открывается локально без аккаунта и сети. Корпус не отправляется платному API. Внешняя разметка QAC служит только документированным обогащением сопоставленных мест.

Установка: `python -m pip install -r requirements.lock.txt`, затем `python -m pip install -e . --no-deps`. Поддерживается Python 3.11+; фактическая версия запуска и библиотеки записываются в манифест. Для воспроизведения снимка используйте сохранённый QAC из data/external; сетевое соединение при пересчёте не требуется.

Полный пересчёт: `python -m quran_analysis --stage all`.
Возобновление с проверкой кэша: `python -m quran_analysis --stage all --resume`.
Выборочный пересчёт статистики с проверенными зависимостями: `python -m quran_analysis --stage statistics --resume` (изменение кода, конфигурации или исходника автоматически делает кэш недействительным).
Принудительный пересчёт выбранного этапа с зависимостями: `python -m quran_analysis --stage statistics`.
Пересборка представления: `python -m quran_analysis --stage presentation --resume`.
Проверки: `python -m pytest -q`; итоговый независимый аудит: `python -m quran_analysis --stage validation --resume`.

Этапы: core → morphology / exploration / statistics → extension → presentation → validation. В раннере зависимости выполняются последовательно; агентами разработка разделялась независимо. Кэш каждого этапа содержит хеш исходника, конфигурации, модуля, ключи зависимостей и хеши файлов результата. Отсутствующий или изменённый результат пересчитывается. Перед дорогими этапами размер пространства фиксируется в SEARCH_SPACE и STATISTICAL_PLAN. `run_manifest.json` сохраняется перед каждым этапом, после завершения и при исключении.

Случайность: seed=20261007; отдельные потоки выводятся из стабильного SHA-256 идентификатора теста. B=999 фиксировано, остановка не зависит от удобного p-value. Времена выполнения и метаданные даты могут изменяться между запусками; содержательные таблицы и симуляции должны воспроизводиться. Сжатые gzip могут иметь разные служебные временные метки — сравнивайте распакованные таблицы, а не только архивный байтовый хеш.

CSV: UTF-8, запятая, стандартное quoting, заголовки; пустое поле — неизвестно/неприменимо, а не ноль. Адреса `2:255` и `2:255:1` импортируются в табличный редактор как текст. `.csv.gz` распаковывается gzip/7-Zip; данные не усечены. В XLSX большие таблицы имеют ссылки на полные выгрузки. Научные выводы нельзя извлекать из одного числа без profile_id, scope и определения единицы.

Подключённый шаблон аналитического приложения в данной среде не был доступен. Применён разрешённый заданием переносимый HTML, работающий без сервера. Публичная публикация не требуется и не выполнялась. Локальная визуальная проверка проводится Chromium/Playwright; сохранённые проверки описаны в report/ и results/validation*.json. Наличие открытого HTML не заменяет независимую проверку расчётов.
