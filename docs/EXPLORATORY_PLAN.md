# Дополнительный цикл после базового анализа

Регистрация: 2026-10-07; **exploratory**, после просмотра базовых частот и пяти наиболее частых повторённых текстов. Перестановочные результаты ещё не использованы для выбора этих вопросов. Сохранение плана до дополнительных расчётов не превращает эти вопросы в независимую предварительную регистрацию.

Наблюдения: в таблице core для plain/file две формы имеют охват 114 сур; для plain/numbered таких форм нет. Наиболее частая одинаковая plain-строка аята встречается 31 раз. План расширения:

1. **Универсальность и вступительные префиксы.** Для всех plain и search форм сравнить частоту и число содержащих их сур, первый/последний token_id при file/numbered. Найти все формы с охватом всех сур, а не подбирать отдельные пары. Вывод точный описательный; p-value не применяется к изменению определения корпуса.
2. **Повторённые аяты и одинаковые окончания.** Сначала определить повтор полного текста аята по последовательности plain-токенов (границы сохранены); отдельно file/numbered. Для каждой суры и всего файла измерить долю соседних пар с одинаковыми последними 2/3 письменными буквами. Повторить расчёт, исключив рёбра, касающиеся любого аята с повторённой последовательностью в корпусе. Новое соседство после исключения не создаётся. Показывать исходные числители, знаменатели и все исключённые рёбра. Это разложение наблюдаемой структуры, не доказательство причинного влияния рефренов и не полный анализ рифмы.
3. **Масштаб простых частотных равенств.** Для всех plain форм сосчитать неупорядоченные пары равных глобальных частот в двух областях. Сохранять группы эквивалентности и их размеры, а не материализовать десятки миллионов пар. Совпадающие пары между областями — группы по паре (частота_file,частота_numbered). Пары со словами, отсутствующими в numbered, исключаются из общего пересечения. Публикуется число сохранённых, потерянных и новых равенств. Нулевая модель не вводится: обилие тривиальных совпадений — точный результат данного пространства и не мера вероятности намеренного устройства.

Условие окончания расширения: полностью рассчитаны эти три разных семейства (границы корпуса, локальные повторы, пространство равенств); остальные направления имеют карту фактического покрытия. Это не доказательство отсутствия иных закономерностей. Стоимость O(N + V + U log U), память O(N + U), N≈78 тыс. токенов. Квадратичный список пар не создаётся.
